# 実機確認リスト

リストの本体は `notes/実機確認リスト.md`（非公開リポジトリ bus75test-notes を `notes/` に置いたもの）。項目ごとに ID（F01 など）と状態（☐ 未確認 ／ ✅ OK ／ ❌ NG ／ ➖ 対象外）がある。

## 表示を頼まれたとき

1. `notes/実機確認リスト.md` を読む。
2. 状態が ☐ と ❌ の項目を、分類（A 音声・再生、B 位置・判定、C 選択画面、D 案内の内容・経路・時間、E 写真、F 運行とのずれ）ごとにまとめて見せる。ID と、確認すること、メモ（推定値などの注意）を付ける。
3. ❌ があれば先頭に出し、直し方の案があれば添える。
4. 最後に、全体の件数（☐・✅・❌）を1行で示す。

## 結果の報告を受けたとき

- 「F12はOK」のように言われたら、その項目の状態を ✅ にし、「結果・メモ」に日付（YYYY-MM-DD）と一言を書く。
- NG の場合は ❌ にして、いつ・どこで・どうなったかをメモに残し、直す対応を提案する（直したら ☐ に戻して、再確認する旨を書く）。
- 先頭の「未確認の件数」と、末尾の「記録」を更新する。
- 更新したら `notes/` の中で commit する（push は利用者に確認してから）。公開リポジトリには、リストの内容を書かない。

## 項目を足すとき

- 新しい機能や、推定・代用で作った部分を入れたら、該当する分類に ID の続き番号で項目を足す。追加日と、確認の仕方、注意（推定値など）を書く。
- 件数も更新する。
